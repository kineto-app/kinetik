## Default Permission

Native credentials and user-visible ongoing work.

#### This default permission set includes the following:

- `allow-secure-get`
- `allow-secure-put`
- `allow-background`
- `allow-file-info`
- `allow-notify`
- `allow-register-listener`
- `allow-remove-listener`
